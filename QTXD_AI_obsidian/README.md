# 🧠 QTXD_AI_Obsidian · 本地知识管理模块

> 本模块基于 Obsidian 搭建，用于记录 AI 系统开发过程中的知识点、每日总结、复盘与技术文档。

---

## 📁 模块结构

| 文件夹 / 文件名 | 用途说明 |
|-----------------|-----------|
| `99_每日学习日志/` | 每天自动生成或手动记录的学习笔记 |
| `00_项目管理/`     | 项目设计、阶段性回顾与规划 |
| `01_爬虫模块/`     | 爬虫功能相关技术笔记 |
| `02_视频模块/`     | 剪映、视频生成相关笔记 |
| `99_代码片段/`     | Python 常用模板、技巧、总结 |

---

## ✍️ 使用方式

- 使用 Obsidian 打开本目录即可读取与编辑
- 推荐使用模板插件、日记插件、Dataview 插件提升管理效率
- 建议每日记录任务总结，配合 Notion 打通知识闭环

---

## ☁️ 自动化构想

- 从 ChatGPT 对话中提取每日总结并写入此模块
- Obsidian ↔ Notion 互同步（计划中）
- 支持每日关键词抽取、错误记录追踪等

---

> 本模块属于 QTXD_AI_system 主舱的一部分，用于开发者本人学习和系统迭代复盘。
